## 4. AI 工具使用说明

### 4.1 使用的 AI 工具

| 工具 | 用途 | 辅助的模块/工作内容 |
|------|------|-------------------|
| AI 编程助手 | 代码结构设计、调试协助、文档撰写 | 状态机架构、轨迹插值函数、文档编写 |

### 4.2 具体辅助内容

**代码开发方面：**
- 协助设计整体架构（状态机 + 轨迹插值 + PD 控制的三层结构）
- 编写五次多项式轨迹插值函数
- 编写 PD 控制循环代码
- 编写姿态调试工具（键盘交互逻辑）
- 协助修复 MuJoCo viewer 键盘回调兼容性问题
- 协助修复日志输出缓冲问题
- 协助排查机器人姿态歪斜问题并提供硬固定方案

**文档编写方面：**
- 协助撰写技术说明文档（关节映射、控制参数、坐标系定义等）
- 协助撰写模型资料文档
- 协助整理问题记录
- 协助撰写运行说明

**设计决策方面：**
- 提供固定基座的多种方案对比（weld / constraint / 硬重置）
- 提供左右臂对称化方法
- 提供进阶阶段跳过的理由说明

### 4.3 人工参与部分

以下内容由人工独立完成或深度调试：
- 三组关键姿态（初始/脸前/展开）的**实际调试与参数确定**（通过 pose_tuner.py 交互式调整）
- PD 参数的**实际调优**（根据仿真效果反复调整）
- 阶段时长的**实际验证**
- 整体动作效果的**视觉评估与调整**
- 演示视频录制

## 5. 代码原创性声明

本项目中以下核心逻辑为独立设计与实现：

| 模块 | 说明 | 原创性 |
|------|------|:------:|
| 状态机（StateMachine） | 阶段调度、状态转移、目标姿态查询 | ✅ 独立实现 |
| 五次多项式轨迹插值器 | 关节空间轨迹规划 | ✅ 独立实现 |
| PD 控制器 | 力矩模式 PD + 速度前馈 + 限幅 | ✅ 独立实现 |
| 动作序列设计 | 三组关键姿态 + 七阶段流程 | ✅ 独立设计 |
| 姿态调试工具 | 交互式键盘调参 | ✅ 独立实现 |
| 安全机制 | 限位保护、速度上限、停止功能 | ✅ 独立实现 |

**第三方资源使用说明**：
- PM01 机器人模型来自开源社区，仅作为仿真对象使用
- MuJoCo 和 NumPy 为通用基础库，按标准方式调用
