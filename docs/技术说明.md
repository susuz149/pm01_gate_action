## 2. 控制参数（Control Parameters）

### 2.1 PD 控制增益

采用力矩模式 PD 控制，各关节增益如下：

| 关节 | Kp (N·m/rad) | Kd (N·m·s/rad) |
|------|:------------:|:--------------:|
| 肩 pitch | 100.0 | 4.0 |
| 肩 roll | 100.0 | 4.0 |
| 肩 yaw | 80.0 | 3.0 |
| 肘 pitch | 80.0 | 3.0 |
| 肘 yaw | 50.0 | 2.0 |

控制律：
```
τ = Kp * (q_target - q_current) + Kd * (qd_target - qd_current)
```

其中：
- `q_target`：目标角度（由轨迹插值器输出）
- `q_current`：当前关节角度（仿真反馈）
- `qd_target`：目标角速度（由轨迹插值器输出）
- `qd_current`：当前关节角速度（仿真反馈）

### 2.2 执行器力矩限制

每个关节的控制力矩被限制在模型定义的 `actuator_ctrlrange` 范围内，防止输出过大力矩。

### 2.3 速度上限

最大关节角速度限制为 **3.0 rad/s**，由轨迹插值器输出时直接裁剪，保证动作安全可控。

## 3. 轨迹方法（Trajectory Generation）

### 3.1 关节空间五次多项式插值

采用**五次多项式（Quintic Polynomial）**进行关节空间轨迹规划，保证：
- 位置连续
- 速度连续
- 加速度连续
- 起止速度 = 0
- 起止加速度 = 0

公式：
```
q(t) = q0 + (q1 - q0) * (10τ³ - 15τ⁴ + 6τ⁵)
qd(t) = (q1 - q0) * (30τ² - 60τ³ + 30τ⁴) / T
```

其中 `τ = t/T`，`T` 为阶段总时长，`t ∈ [0, T]`。

### 3.2 为什么选五次多项式

| 插值方法 | 位置连续 | 速度连续 | 加速度连续 | 平滑度 |
|---------|:-------:|:-------:|:---------:|:------:|
| 线性插值 | ✅ | ❌ | ❌ | 差（有急停） |
| 三次多项式 | ✅ | ✅ | ❌ | 中（加速度突变） |
| **五次多项式** | ✅ | ✅ | ✅ | **好** |

五次多项式在起止点的速度和加速度均为 0，阶段切换时无冲击，动作最自然。

### 3.3 各阶段时长

| 阶段 | 名称 | 时长（s） | 起点姿态 | 终点姿态 |
|------|------|:---------:|---------|---------|
| 1 | 初始状态 | 1.0 | INIT | INIT（保持） |
| 2 | 抬起至中心 | 1.5 | INIT | CENTER |
| 3 | 两侧展开（开闸） | 1.5 | CENTER | OPEN |
| 4 | 返回中心（关闸） | 1.5 | OPEN | CENTER |
| 7 | 平滑复位 | 1.5 | CENTER | INIT |

一个完整周期约 **7.0 秒**（不含选做阶段、仿真时间！！）。

## 4. 坐标系定义（Coordinate System）

### 4.1 世界坐标系

- **原点**：地面中心
- **X 轴**：机器人正前方
- **Y 轴**：机器人左侧
- **Z 轴**：竖直向上
- **单位**：米（m）

### 4.2 基座坐标系

基座位于躯干中心，初始时与世界坐标系重合：
- 基座高度（Z）：0.82 m（脚底到躯干中心高度）
- 朝向：初始四元数 `[1, 0, 0, 0]`（面向 +X 方向）

### 4.3 关节旋转方向（右手定则）

| 关节 | 正值旋转方向 | 直观描述 |
|------|-------------|---------|
| 肩 pitch | 绕 Y 轴旋转 | 负值：手臂向前抬起；正值：手臂向后摆 |
| 肩 roll（左） | 绕 X 轴旋转 | 正值：手臂向外展开 |
| 肩 roll（右） | 绕 X 轴旋转 | 负值：手臂向外展开 |
| 肩 yaw | 绕 Z 轴旋转 | 正值：手臂外旋；负值：手臂内旋 |
| 肘 pitch | 绕 Y 轴旋转 | 负值：小臂弯曲（靠近大臂） |
| 肘 yaw | 绕 X 轴旋转 | 正值：小臂外旋 |

> **注意**：左右臂的 roll 和 yaw 方向镜像对称——左臂正值向外/外旋，右臂负值向外/外旋。

## 5. 动作规划思路（Action Planning）

### 5.1 整体策略

采用**关节空间 + 状态机**的分层架构：

```
┌─────────────────────────────┐
│       状态机（FSM）          │  调度阶段切换
├─────────────────────────────┤
│   五次多项式轨迹生成器        │  计算目标角度/速度
├─────────────────────────────┤
│      PD 控制器               │  计算驱动力矩
├─────────────────────────────┤
│     MuJoCo 物理仿真           │  执行 + 反馈
└─────────────────────────────┘
```

### 5.2 各阶段目标姿态

三组关键姿态（弧度，顺序：[肩pitch, 肩roll, 肩yaw, 肘pitch, 肘yaw]）：

| 姿态 | 左臂 | 右臂 | 对应阶段 |
|------|------|------|---------|
| **INIT（初始下垂）** | [0.05, 0.15, -0.1, -0.2, 0.0] | [0.05, -0.15, 0.1, -0.2, 0.0] | 阶段 1、7 |
| **CENTER（脸前中心）** | [-1.95, 1.05, -1.15, -1.8, 1.9] | [-1.95, -1.05, 1.15, -1.8, -1.9] | 阶段 2、4 |
| **OPEN（两侧展开）** | [-2.05, 1.25, -1.05, -0.3626, 0.9] | [-2.05, -1.25, 1.05, -0.3626, -0.9] | 阶段 3 |

姿态通过 `pose_tuner.py` 交互式调试确定，保证左右镜像对称。

### 5.3 双臂协调

左右臂共享同一时间轴，同步开始和结束各阶段：
- 阶段 2：双臂同时从下垂抬到脸前
- 阶段 3：双臂同时从中心向两侧展开
- 阶段 4：双臂同时从两侧回到中心
- 阶段 7：双臂同时从脸前放回身体两侧

### 5.4 安全机制

1. **关节限位保护**：每帧对目标角度做 clip，确保在 `jnt_range` 范围内
2. **速度上限**：轨迹输出的目标角速度限制在 ±3.0 rad/s
3. **力矩限幅**：PD 输出的力矩限制在 `actuator_ctrlrange` 内
4. **固定基座**：每步硬重置基座位置和姿态，防止机器人倾倒
5. **停止功能**：按 S 键可随时停止，保持当前姿态

## 6. 状态机设计（State Machine）

### 6.1 状态转移图

```
┌─────┐    1.0s     ┌─────┐    1.5s     ┌─────┐
│  1  │ ──────────▶ │  2  │ ──────────▶ │  3  │
│初始 │             │抬起 │             │展开 │
└─────┘             └─────┘             └─────┘
    ▲                  │                   │
    │                  │ 1.5s              │ 1.5s
    │                  ▼                   ▼
    │               ┌─────┐             ┌─────┐
    │               │  7  │ ◀────────── │  4  │
    │               │复位 │             │收回 │
    │               └─────┘             └─────┘
    │                  │
    └──────────────────┘
         1.0s 停留
```

> 选做阶段 5、6 被跳过（模型无腕关节）。

### 6.2 状态机接口

| 方法 | 功能 |
|------|------|
| `update(t)` | 推进状态机，检查是否需要切换阶段 |
| `get_target(t)` | 返回当前时刻左右臂的目标角度和速度 |
| `reset(t)` | 重置到阶段 1 |
| `stop()` | 停止切换（保持当前阶段） |
| `toggle_pause()` | 暂停/继续 |

## 7. 基座固定方案

任务书允许固定基座。本项目采用**每步硬重置法**：

```python
# 每步仿真后执行
data.qpos[0:7] = [0, 0, 0.82, 1, 0, 0, 0]   # 位置 + 四元数
data.qvel[0:6] = 0                           # 线速度 + 角速度
```

同时对腿部、腰部、头部关节也采用同样的硬固定策略，保证上半身动作时下半身完全稳定，不影响动作观察。

**优点**：实现简单，绝对稳定，调试上肢动作时无干扰。
**局限**：基座不是物理固定，不反映真实接触力学。但任务书明确允许，满足考核要求。
